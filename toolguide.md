# Tool Guide

We will be using the following tools in this course:

- **Data manipulation and analysis**: [pandas](https://pandas.pydata.org/)
  - Documentation: https://pandas.pydata.org/docs/
  - Intro tutorial: https://pandas.pydata.org/docs/getting_started/intro_tutorials/index.html
- **Visualization**: [plotly](https://plotly.com/)
  - Documentation: https://plotly.com/python/
  - Intro tutorial: https://plotly.com/python/getting-started/
- **Modeling and machine learning**: [Scikit-learn](https://scikit-learn.org/stable/)
  - Documentation: https://scikit-learn.org/stable/documentation.html
  - Intro tutorial: https://scikit-learn.org/stable/tutorial/basic/tutorial.html
- **Writing and publishing**: Jupyter Notebooks hosted in [Google Colab](https://colab.research.google.com/)
    - Intro tutorial: https://colab.research.google.com/notebooks/intro.ipynb
